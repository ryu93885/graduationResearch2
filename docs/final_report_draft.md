# 胸部X線画像の肺炎分類・検出モデルの判断根拠と医師のアノテーションの比較【未定：題目は仮】

## 要旨【未実施】

結果が出たあとに書く。

## 第1章 序論

### 1.1 研究背景

医療分野でも AI のモデルが活用されている。希少な症例では専門医の読影に劣るものの、一般的な症例では同等以上の性能を示す例がある。しかし、深層学習の判断の根拠は外から見えにくく、その説明可能性は依然として議論の対象である。このことが、医療現場への導入が限られている一因である。分類の精度だけでは、モデルが画像のどの部分を根拠にしたかは分からず、撮影条件や文字マーカーなど、病変と関係のない手がかりを使っている可能性もある。

本研究では、医師が肺炎を疑う陰影として囲んだ領域を「医師のアノテーション領域」と呼ぶ。RSNA の BBox は陰影を囲む長方形であり、病変の正確な輪郭ではない。そのため、本研究でいう「整合」は、医師の診断の過程全体との一致ではなく、医師のアノテーション領域との一致を指す。

### 1.2 研究目的

本研究は、胸部X線画像から肺炎の所見（Lung Opacity）を判定するモデルの判断根拠を可視化する。分類モデルについては、説明可能な AI（XAI）の手法である Grad-CAM を用いる。検出モデルについては、検出した BBox そのものがモデルの注目した位置を示すため、これを判断根拠とみなす。そのうえで、判断根拠が医師のアノテーション（BBox）と整合するかを検証し、AI の判断の信頼性を評価する。また、医師と異なる根拠に基づく判断がある場合に、それが新たな視点での画像検出につながりうるかを併せて検証する。

### 1.3 研究課題【案】

- **RQ1**：深層学習モデル（分類・検出）は、ルールベースの方法より有用か。
- **RQ2**：モデルの判断根拠（分類モデルの Grad-CAM、検出モデルの BBox）は、医師の BBox と整合するか。
- **RQ3**：医師の BBox と整合しない判断根拠は、ショートカットと付け忘れの可能性を除いたうえで、ほかの画像と比べて確からしい根拠といえるか。

### 1.4 仮説と判定基準【未定】

仮説と、それを判定する基準は、テストデータを使う前に決めて記録する。判定に用いる評価指標は第4章で決めている。

モデルが医師のアノテーション領域の外に反応しただけでは、医学的に有用な新しい所見を見つけたとはいえない。撮影条件、文字マーカー、医療機器、データセットに固有の偏り（ショートカット学習）や、付け忘れた陰影の可能性を先に検討する（4.9 節）。

## 第2章 関連研究【要確認：書誌情報は原典で確認する】

### 2.1 データセット

RSNA Pneumonia Detection Challenge (2018) のデータは、NIH の胸部X線データセットから選んだ正面像 30,000 枚に、放射線科医が肺炎を疑う陰影の BBox と3クラスのラベルを付けたものである [5]。

### 2.2 モデル

画像分類には、残差結合により深い層の学習を可能にした ResNet [1] を用いる。BBox の検出には、領域候補ネットワーク（RPN）と RoI Heads からなる2段階の検出器 Faster R-CNN [2] に、複数の解像度の特徴を組み合わせる FPN [3] を加えたものを用いる【協議中：検出モデルの種類】。

### 2.3 判断根拠の可視化と評価

Grad-CAM [4] は、対象のスコアの、最後の畳み込み層の特徴マップに対する勾配から、判断に寄与した位置を示すマップを作る。原論文は、マップから作った BOX と正解 BOX の IoU による局在の評価と、pointing game [6] による評価を行っている。胸部X線では、Saporta ら [7] が複数の説明手法を、mIoU と hit rate（pointing game と同じ定義）で比較している。

### 2.4 ショートカット学習

深層学習のモデルは、本来の所見ではなく、撮影条件や写り込みなどの見かけの手がかり（ショートカット）を使うことがある [8, 9, 10]。判断根拠が医師のアノテーションと異なる場合は、まずこの可能性を検討する必要がある。

## 第3章 データセット

### 3.1 使用するデータ

RSNA Pneumonia Detection Challenge (2018) の公式配布データを用いる。各画像には、最終ラベルとして Lung Opacity、No Lung Opacity / Not Normal、Normal のいずれかが付いている。Lung Opacity の画像には、陰影の位置を示す BBox が付いている。本研究では最終ラベルのみを用いる。最終ラベルのない画像は用いない。

同じデータセットを用いた先行の作業（graduationResearch）では、次の値が得られている。本研究でデータを取得したあとに再確認する【要確認】。

| 項目 | 値 | 本研究との関係 |
|---|---|---|
| 最終ラベルのある画像 | 29,684 枚（最終ラベルのない画像は 316 枚） | 最終ラベルのない画像は用いない |
| クラスの割合 | Lung Opacity 7,106 枚（23.9%）、No Lung Opacity / Not Normal 12,788 枚（43.1%）、Normal 9,790 枚（33.0%） | クラスの偏りは大きくないため、正解率も評価に使える |
| 撮影方向 | Lung Opacity の画像の 77.3% が AP（全体では 45.7%）。撮影方向だけで Lung Opacity を予測した ROC-AUC は 0.708 | ショートカットになりうるため、AP と PA に分けて評価する（4.9 節） |

### 3.2 前処理

1024×1024 の画像を 512×512 に縮小し、グレースケールを3チャンネルに複製してモデルに入力する。BBox の座標も同じ比率で縮小する。

### 3.3 データ分割

患者単位で、学習用（train）70%、検証用（val）10%、テスト用（test）20% に1回分割する。同じ患者の画像が複数の分割に入らないようにするためである。⓪・modelA・modelB で同じ分割を用いる。調整と閾値の決定はすべて検証用データで行い、テストデータはモデルと閾値を固定したあとに1回だけ用いる。

- 【未定】クラスの比率をそろえる層化を行うかは、分割のプログラムを作るときに決める。

### 3.4 データの取得

公式配布ページから Python で取得する。本研究でのデータの取得は【未実施】である。先行の作業で作った取得用のプログラムを再利用するかは【未定】である。

## 第4章 方法

### 4.1 全体の流れ

1. ⓪ ルールベースで「Lung Opacity か否か」の2値分類を行い、比較の基準とする。
2. ① modelA（ResNet【協議中：ResNet-101 か ResNet-50 か】）で3クラス分類を学習する。
3. ② modelB（Faster R-CNN【協議中：検出モデルの種類】）で Lung Opacity の BBox 検出を学習する。
4. ⓪・modelA・modelB を、テストデータの「Lung Opacity か否か」の正解率と混同行列で比べる。
5. ③ テストデータで、modelA の Grad-CAM と modelB の検出 BBox を医師の BBox と比べ、整合を評価する。整合しない根拠は 4.9 節の手順で検証する。

本研究の modelA・modelB は分類モデルと検出モデルを指し、2026-11-05 版の進捗報告書の Model A・B・C（入力する領域だけが異なる3つの分類モデル）とは別物である。

### 4.2 ⓪ ルールベースの分類

画像の特徴を分析して規則を設計し、「Lung Opacity か否か」の2値分類に用いる。BBox の検出は行わない。白いピクセルの量や密度など、肺炎の画像に見られる特徴をいくつか組み合わせて、簡易的なルールベースのモデルを作る。閾値と特徴の組み合わせは、学習用データの特徴の分布を見て手で決め、検証用データで確かめる。テストデータは最後に1回だけ用いる。このモデルは、深層学習のモデルの有用性を確かめるための比較の基準とする。古典的な画像処理は手間のわりに成果が小さいという指導教員の指摘を受け、範囲を2値分類に絞った。

| 項目 | 設定 | 状態 |
|---|---|---|
| 課題 | 2値分類（Lung Opacity か否か）。BBox の検出は行わない | 決定 |
| 拡張 | 2値分類がうまくいけば、3クラス分類に広げることを検討する | 【案】 |
| 特徴 | 白いピクセルの量や密度など。具体的な特徴は学習用データを分析して選ぶ | 方針は決定。特徴は実装時に選ぶ |
| 規則の決め方 | 学習用データの特徴の分布を見て、閾値と組み合わせを手で決める | 決定 |
| 特徴を計算する範囲 | 画像全体（画像ごとに明るさをそろえる）、決まった範囲、肺野のいずれか | 【未定】 |
| かける期間の上限 | — | 【未定】 |

白いピクセルは、陰影だけでなく、骨・心臓・チューブ類・文字や、撮影方向（AP/PA）による明るさの違いでも増える。そのため、特徴を計算する範囲は実装の前に決める。

### 4.4 ② modelB：画像検出

Faster R-CNN は、modelA と同じ ResNet の構造を持ち評価しやすいため、使う予定である。指導教員からは、実装しやすい YOLO か、手元にコードがある Mask R-CNN から始めることが提案されている。検出モデルの種類は【協議中】である。RSNA には BBox しかなくマスクの正解がないため、Mask R-CNN のマスクを予測する部分は学習できない。torchvision の Mask R-CNN は Faster R-CNN にマスクを予測する部分を加えたものなので、手元のコードからその部分を外せば Faster R-CNN として使える。

| 項目 | 設定 | 状態 |
|---|---|---|
| 検出モデル | torchvision の Faster R-CNN と FPN | 【協議中】（YOLO、手元の Mask R-CNN のコードからマスクの部分を外す案） |
| バックボーン | ResNet-101 + FPN（modelA を変える場合は ResNet-50 + FPN） | 【協議中】 |
| パラメータ数 | ResNet-101 + FPN で 60,239,065、ResNet-50 + FPN で 41,299,161（2クラス、BN 固定） | バックボーンによる |
| 予測層 | 分類用 1024→2（背景と Lung Opacity）、BOX 回帰用 1024→8 | 決定 |
| 事前学習の重み | バックボーンは「modelA と同じ」。ImageNet の重みか、学習済みの modelA の重みか。FPN・RPN・RoI Heads は新しく学習する | 【協議中】 |
| 固定する層 | 最初の畳み込み層と layer1。BN も固定する | 現在の計画 |
| 最適化・学習率・バッチサイズ | SGD（momentum 0.9、weight decay 5e-4）。画像1枚あたり 0.001（バッチ 4 なら 0.004、8 なら 0.008）。バッチサイズ 4〜8 | 現在の計画 |

### 4.5 目標値（参考値）【協議中】

| モデル | 値 | 根拠 |
|---|---|---|
| modelA | 検証用データのマクロ平均 ROC-AUC 0.80 以上 | AUC の評価の目安で 0.8〜0.9 を excellent とする区分 [11] の下限。RSNA の3クラス分類のマクロ平均 AUC の報告は見つからなかった |

### 4.7 ③ 判断根拠の可視化

**modelA**：Grad-CAM [4] を用いる。原論文にならい、最後の畳み込み層（ResNet の `layer4`）の特徴マップと、Lung Opacity クラスの softmax をかける前のスコアの勾配を用いる。512 px の入力では 16×16 のマップになるため、512 に拡大して医師の BBox と比べる。

**modelB**：Grad-CAM は用いない。検出モデルは BOX そのものがモデルの注目した位置を示し、また検出モデルの前半は分類モデルと同じ構造であるため、Grad-CAM から新しい情報は得にくいという指導教員の指摘による。検出した BOX を、そのまま modelB の判断根拠とみなす。

### 4.8 判断根拠と医師のアノテーションの整合の評価

#### 4.8.1 modelA（Grad-CAM）

テストデータの Lung Opacity の画像（医師の BBox がある画像）で、次の指標を求める。

| 区分 | 指標 | 定義 | 出典 |
|---|---|---|---|
| 主 | 局在の正解率 | CAM を最大値の 15% で二値化し、最も大きい連結領域を囲む BOX を作る。医師の BOX のいずれかとの IoU が 0.5 以上なら正解 | Grad-CAM の原論文 [4] |
| 主 | Pointing game の的中率 | CAM の最大値の位置が医師の BOX のいずれかの中にあれば的中 | [4, 6] |
| 補助 | mIoU | 二値化した CAM と医師の BOX の領域（複数なら和集合）の IoU の平均。閾値は検証用データで mIoU が最大になる値とする | Saporta ら [7] |

- 局在が正解（IoU 0.5 以上）の画像を、「判断根拠が医師のアノテーションと整合する」とみなす。
- Pointing game の偶然の的中率（BOX が画像に占める面積の割合）を併せて示し、的中率がこれを上回るかを確かめる。
- モデルが正しく判定した画像と判定しなかった画像、1人読影と3人読影の画像を分けて報告する。
- 割合には、患者単位のブートストラップによる 95% 信頼区間を付ける。
- Grad-CAM の健全性チェック（モデルの重みをランダムにしたときに CAM が変わることを確かめる [14]）を加えるかは【未定】である。

#### 4.8.2 modelB（検出 BBox）

テストデータの全画像で、確信度が閾値以上の検出 BOX を、医師の BBox との重なりで次の3つに分けて数える。

| 区分 | 定義 | 扱い |
|---|---|---|
| 一致 | 医師の BBox のいずれかと IoU 0.5 以上 | BOX 単位の評価の正解とする |
| 位置のずれ | 医師の BBox と重なるが、IoU が 0.5 未満 | 位置の誤差として数える |
| 医師と異なる根拠の候補 | どの医師の BBox とも重ならない（IoU = 0）。医師の BBox がない陰性画像の検出も含む | 4.9 節の手順で検証する |

少しでも重なる検出は、同じ陰影を指していて位置がずれているだけの可能性が高い。そのため、「医師と異なる根拠」の候補は、まったく重ならない検出に限る。

### 4.9 医師と異なる根拠の検証

modelA の Grad-CAM が医師の BBox の外に強く反応した場合や、modelB が医師の BBox と重ならない位置を検出した場合（4.8.2 節）でも、ただちに新たな根拠とはみなさない。深層学習のモデルはショートカットを使うことがあり [8, 9, 10]、また BBox の付け忘れも考えられるためである。そこで、次の3つの要因を順に検討し、それで説明できる反応を除く。

1. **撮影条件**：肺炎の陽性画像は、ポータブル撮影（AP）に大きく偏っている（3.1 節）。AP と PA に分けて分類性能と整合の指標を求め、根拠の傾向が撮影方向で変わらないかを確かめる。
2. **写り込み**：文字マーカー、チューブやカテーテル、心電図の電極など、所見と関係のない写り込みに CAM が反応していないか、また modelB の BOX がそれらを検出していないかを目視で確かめる。CAM の最大値や BOX が肺野の外にある画像は、特に詳しく確かめる。
3. **BBox の付け忘れ**：多くの画像は1人の読影医が読んでいる。BBox の外の反応が、付け忘れた陰影に当たっている可能性がある。複数（3人）の読影医が読んだ画像でも同じ傾向が出るかを確かめる。

これらで説明できない反応が、多くの画像で同じ解剖学的な位置に繰り返し現れる場合に、「確からしい根拠」の候補とする。候補については、指導教員や専門医の意見を聞いて最終的に判断する。

### 4.10 研究課題との対応

| 研究課題 | 検証の方法 |
|---|---|
| RQ1：深層学習の有用性 | ⓪・modelA・modelB の正解率と混同行列を、同じテストデータで比べる（4.6 節） |
| RQ2：判断根拠と医師のアノテーションの整合 | modelA は局在の正解率・pointing game の的中率・mIoU を偶然の水準と比べる（4.8.1 節）。modelB は検出 BOX の3区分の割合を求める（4.8.2 節） |
| RQ3：医師と異なる根拠の確からしさ | 3段階の確認（4.9 節）のあと、残った候補を指導教員や専門医と検討する。可視化だけで新たな医学的所見とは主張しない |

## 第6章 考察【未実施】

### 6.1 結果の考察【未実施】

Grad-CAM のマップが医師の BBox と一致しても、分類モデルが医師のアノテーション領域に反応していることを示すだけで、医師と同じ考え方で判断していることまでは示さない。逆に、一致しないことも、それだけでは新しい所見を意味しない。XAI の研究の質に対する指導教員の懸念を踏まえ、評価指標を結果の前に決め、偶然の水準と比べ、ショートカットと付け忘れを先に検討し、医学的な解釈は指導教員や専門医の意見を聞いて慎重に行う。

### 6.2 限界【案】

| 限界 | 研究への影響 | 対策 |
|---|---|---|
| BBox は病変の正確な輪郭ではない | BOX の中に正常な部分が入り、陰影が BOX の外にはみ出すことがある | IoU による基準を用い、「医師のアノテーション領域」と呼んで限界を明記する |
| 1人読影のアノテーション | 付け忘れた陰影があると、正しい反応が不一致に見える | 3人読影の画像で同じ分析を行う（4.9 節） |
| ショートカット学習 | 撮影方向、文字マーカー、医療機器が予測を左右しうる | AP・PA に分けて評価し、写り込みを目視で確かめる（4.9 節） |
| Grad-CAM の粗さ | 16×16 のマップでは位置はおおまかにしか分からない | 最大値の位置だけを使う pointing game を IoU の指標と併せて報告し、限界を明記する |
| XAI の解釈の限界 | ヒートマップはモデルの判断過程の完全な説明ではない | 指標を事前に決め、偶然の水準と比べる。健全性チェックは【未定】。因果的な主張はしない |
| ルールベースにかける手間 | 古典的な手法は手間のわりに成果が小さいことがある | 2値分類に絞る。期間の上限は【未定】 |
| データセットの選び方 | 肺炎が疑われる画像を多く含むように選ばれており、陽性の割合は臨床と異なる | 適合率などの値を、そのまま臨床に一般化しない |
| データのリーク | 同じ患者の画像が複数の分割に入ると性能を過大に評価する | 患者単位で分割し、テストデータは1回だけ用いる |
