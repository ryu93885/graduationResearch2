# 胸部X線画像の肺炎分類・検出モデルの判断根拠と医師のアノテーションの比較【案：題目は未確定】

## 要旨【未実施】

結果が出たあとに書く。

## 第1章 序論

### 1.1 研究背景

医療分野でも AI のモデルが活用されている。希少な症例では専門医の読影に劣るものの、一般的な症例では同等以上の性能を示す例がある。しかし、深層学習の判断の根拠は外から見えにくく、その説明可能性は依然として議論の対象である。このことが、医療現場への導入が限られている一因である。

### 1.2 研究目的

本研究は、胸部X線画像から肺炎の所見（Lung Opacity）を判定するモデルの判断根拠を可視化する。分類モデルについては、説明可能な AI（XAI）の手法である Grad-CAM を用いる。検出モデルについては、検出した BBox そのものがモデルの注目した位置を示すため、これを判断根拠とみなす。そのうえで、判断根拠が医師のアノテーション（BBox）と整合するかを検証し、AI の判断の信頼性を評価する。また、医師と異なる根拠に基づく判断がある場合に、それが新たな視点での画像検出につながりうるかを併せて検証する。

### 1.3 研究課題【案】

- **RQ1**：深層学習モデル（分類・検出）は、ルールベースの方法より有用か。
- **RQ2**：モデルの判断根拠（分類モデルの Grad-CAM、検出モデルの BBox）は、医師の BBox と整合するか。
- **RQ3**：医師の BBox と整合しない判断根拠は、ほかの画像と比べて確からしい根拠といえるか。

## 第2章 関連研究【要確認：書誌情報は原典で確認する】

### 2.1 データセット

RSNA Pneumonia Detection Challenge (2018) のデータは、NIH の胸部X線データセットから選んだ正面像 30,000 枚に、放射線科医が肺炎を疑う陰影の BBox と3クラスのラベルを付けたものである [5]。

### 2.2 モデル

画像分類には、残差結合により深い層の学習を可能にした ResNet [1] を用いる。BBox の検出には、領域候補ネットワーク（RPN）と RoI Heads からなる2段階の検出器 Faster R-CNN [2] に、複数の解像度の特徴を組み合わせる FPN [3] を加えたものを用いる。

### 2.3 判断根拠の可視化と評価

Grad-CAM [4] は、対象のスコアの、最後の畳み込み層の特徴マップに対する勾配から、判断に寄与した位置を示すマップを作る。原論文は、マップから作った BOX と正解 BOX の IoU による局在の評価と、pointing game [6] による評価を行っている。胸部X線では、Saporta ら [7] が複数の説明手法を、mIoU と hit rate（pointing game と同じ定義）で比較している。

### 2.4 ショートカット学習

深層学習のモデルは、本来の所見ではなく、撮影条件や写り込みなどの見かけの手がかり（ショートカット）を使うことがある [8, 9, 10]。判断根拠が医師のアノテーションと異なる場合は、まずこの可能性を検討する必要がある。

## 第3章 データセット

### 3.1 使用するデータ

RSNA Pneumonia Detection Challenge (2018) の公式配布データを用いる。各画像には、最終ラベルとして Lung Opacity、No Lung Opacity / Not Normal、Normal のいずれかが付いている。Lung Opacity の画像には、陰影の位置を示す BBox が付いている。本研究では最終ラベルのみを用いる。

- 【要確認】データの枚数、クラスごとの枚数、最終ラベルのない画像の数は、本研究でデータを取得したあとに確認して記載する。

### 3.2 前処理

1024×1024 の画像を 512×512 に縮小し、グレースケールを3チャンネルに複製してモデルに入力する。BBox の座標も同じ比率で縮小する。

### 3.3 データ分割

患者単位で、学習用（train）70%、検証用（val）10%、テスト用（test）20% に1回分割する。同じ患者の画像が複数の分割に入らないようにするためである。

- 【未確定】クラスの比率をそろえる層化を行うかは、分割のプログラムを作るときに決める。

## 第4章 方法

### 4.1 全体の流れ

1. ⓪ ルールベースで「Lung Opacity か否か」の2値分類を行い、比較の基準とする。
2. ① modelA（ResNet-101【未確定：Q-28】）で3クラス分類を学習する。
3. ② modelB（Faster R-CNN【未確定：Q-32】）で Lung Opacity の BBox 検出を学習する。
4. ⓪・modelA・modelB を、テストデータの「Lung Opacity か否か」の正解率と混同行列で比べる。
5. ③ テストデータで、modelA の Grad-CAM と modelB の検出 BBox を医師の BBox と比べ、整合を評価する。整合しない根拠は 4.9 節の手順で検証する。

### 4.2 ⓪ ルールベースの分類

画像の特徴を分析して規則を設計し、「Lung Opacity か否か」の2値分類に用いる。BBox の検出は行わない。白いピクセルの量や密度など、肺炎の画像に見られる特徴をいくつか組み合わせて、簡易的なルールベースのモデルを作る。閾値と特徴の組み合わせは、学習用データの特徴の分布を見て手で決め、検証用データで確かめる。テストデータは最後に1回だけ用いる。このモデルは、深層学習のモデルの有用性を確かめるための比較の基準とする。

- 【案】2値分類がうまくいけば、3クラス分類に広げることを検討する。
- 【未確定】特徴を計算する範囲（画像全体、決まった範囲、肺野。Q-26）と、かける期間の上限は決まっていない。

### 4.3 ① modelA：画像分類

- 【未確定】指導教員の指摘を受け、バックボーンを ResNet-50 にするか（Q-28）、学習を「最大 epoch 数と patience を固定し、標準の設定と2〜3の別の設定から検証用データで選ぶ」方法にするか（Q-29）、学習の評価を正解率と混同行列で行うか（Q-30）を検討している。下の表は 2026-11-18 版の構成の設定である。

| 項目 | 設定 |
|---|---|
| モデル | torchvision の ResNet-101。fc（2048→1000）を Linear（2048→3）に変える |
| パラメータ数 | 42,500,160 + 6,147 = 42,506,307 |
| 事前学習の重み | ImageNet（IMAGENET1K_V2） |
| 学習する範囲 | 全層 |
| 出力 | 3クラスの確率（softmax） |
| 損失関数 | 交差エントロピー |
| 最適化 | SGD（momentum 0.9、weight decay 1e-4） |
| 学習率 | 0.001〜0.01 の中から検証用データで決める |
| バッチサイズ | 16〜32（学習にかかる時間を見て決める） |
| 学習の終了 | 検証用データの指標が一定の epoch 数改善しなければ終える |

### 4.4 ② modelB：画像検出

- 【未確定】指導教員の指摘を受け、検出モデル（手元の Mask R-CNN のコードからマスクを予測する部分を外して Faster R-CNN として使う案など。Q-32）、バックボーン（Q-28）、学習の進め方（Q-29）を検討している。下の表は 2026-11-18 版の構成の設定である。

### 4.5 目標値と学習のやり直しの規則

- 【未確定】学習の進め方を指導教員の方法（Q-29）にする場合、学習は「目標値に届くまでやり直す」のではなく、「標準の設定と別の設定の中から検証用データで選ぶ」形になり、下の目標値は結果を見るための参考値になる（Q-30）。

目標値は、参考にした論文の値を優先し、なければ一般的な値から決めた。参考にした論文（[1]〜[5]）には、本研究と同じ課題の性能の値がないため、一般的な値を用いた。

| モデル | 目標値 | 根拠 |
|---|---|---|
| modelA | 検証用データのマクロ平均 ROC-AUC **0.80 以上** | AUC の評価の目安で 0.8〜0.9 を excellent とする区分 [11] の下限 |
| modelB | 検証用データの mAP（IoU 0.5）**0.40 以上** | RSNA での検出の報告値（改良した Faster R-CNN で 39.23% [12]、ほかの検出器で 45〜50% [13]）の下の方の値【要確認：各論文の評価条件】 |

目標値に届かない場合は、損失関数、最適化手法、学習率などを見直して学習をやり直す。この判断は検証用データの値だけで行う。テストデータは、モデルと閾値を固定したあとに1回だけ用いる。

### 4.6 分類・検出の性能の評価

- **modelA**：正解率、クラスごとの適合率・再現率・F値、マクロ平均 F値、クラスごとの ROC-AUC、混同行列。
- **modelB**：BOX 単位では、IoU 0.5 以上を正解として適合率・再現率・F値・mAP を求める。画像単位では、確信度が閾値以上の BOX が1つ以上ある画像を陽性として、正解率と混同行列を求める。確信度の閾値は検証用データで決めて固定する。指導教員の指摘を受け、ROC は用いない。
- 【未確定】modelA の学習の評価に用いる指標（正解率か、マクロ平均 ROC-AUC か）は、指導教員と相談して決める（Q-30）。

⓪・modelA・modelB は、同じテストデータで「Lung Opacity か否か」の2値の判定に直し、正解率と混同行列で比べる。

| 方法 | 画像を陽性（Lung Opacity）とする条件 |
|---|---|
| ⓪ ルールベース | ルールが陽性と判定した |
| modelA | 3クラスの確率が最も高いクラスが Lung Opacity である |
| modelB | 確信度が閾値以上の BOX が1つ以上ある |

### 4.7 ③ 判断根拠の可視化

**modelA**：Grad-CAM [4] を用いる。原論文にならい、最後の畳み込み層（ResNet の `layer4`）の特徴マップと、Lung Opacity クラスの softmax をかける前のスコアの勾配を用いる。512 px の入力では 16×16 のマップになるため、512 に拡大して医師の BBox と比べる。

**modelB**：Grad-CAM は用いない。検出モデルは BOX そのものがモデルの注目した位置を示し、また検出モデルの前半は分類モデルと同じ構造であるため、Grad-CAM から新しい情報は得にくいという指導教員の指摘による。検出した BOX を、そのまま modelB の判断根拠とみなす。

### 4.8 判断根拠と医師のアノテーションの整合の評価

#### 4.8.1 modelA（Grad-CAM）

テストデータの Lung Opacity の画像（医師の BBox がある画像）で、次の指標を求める。

| 区分 | 指標 | 定義 | 出典 |
|---|---|---|---|
| 主 | 局在の正解率 | CAM を最大値の 15% で二値化し、最も大きい連結領域を囲む BOX を作る。医師の BOX のいずれかとの IoU が 0.5 以上なら正解 | Grad-CAM の原論文 [4] |
| 主 | Pointing game の的中率 | CAM の最大値の位置が医師の BOX のいずれかの中にあれば的中 | [4, 6] |
| 補助 | mIoU | 二値化した CAM と医師の BOX の領域（複数なら和集合）の IoU の平均。閾値は検証用データで mIoU が最大になる値とする | Saporta ら [7] |

- 局在が正解（IoU 0.5 以上）の画像を、「判断根拠が医師のアノテーションと整合する」とみなす。
- Pointing game の偶然の的中率（BOX が画像に占める面積の割合）を併せて示し、的中率がこれを上回るかを確かめる。
- モデルが正しく判定した画像と判定しなかった画像、1人読影と3人読影の画像を分けて報告する。
- 割合には、患者単位のブートストラップによる 95% 信頼区間を付ける。
- 【案】Grad-CAM の健全性チェックとして、モデルの重みをランダムにしたときに CAM が変わることを確かめる [14]（Q-34）。

#### 4.8.2 modelB（検出 BBox）

テストデータの全画像で、確信度が閾値以上の検出 BOX を、医師の BBox との重なりで次の3つに分けて数える。

| 区分 | 定義 | 扱い |
|---|---|---|
| 一致 | 医師の BBox のいずれかと IoU 0.5 以上 | BOX 単位の評価の正解とする |
| 位置のずれ | 医師の BBox と重なるが、IoU が 0.5 未満 | 位置の誤差として数える |
| 医師と異なる根拠の候補【案】 | どの医師の BBox とも重ならない（IoU = 0）。医師の BBox がない陰性画像の検出も含む | 4.9 節の手順で検証する |

少しでも重なる検出は、同じ陰影を指していて位置がずれているだけの可能性が高い。そのため、「医師と異なる根拠」の候補は、まったく重ならない検出に限る。

### 4.9 医師と異なる根拠の検証

modelA の Grad-CAM が医師の BBox の外に強く反応した場合や、modelB が医師の BBox と重ならない位置を検出した場合（4.8.2 節）でも、ただちに新たな根拠とはみなさない。深層学習のモデルはショートカットを使うことがあり [8, 9, 10]、また BBox の付け忘れも考えられるためである。そこで、次の3つの要因を順に検討し、それで説明できる反応を除く。

1. **撮影条件**：肺炎の陽性画像は、ポータブル撮影（AP）に大きく偏っている。先行して行ったデータの確認では、陽性画像の 77.3% が AP であり（全体では 45.7%）、撮影方向だけで陽性を予測しても ROC-AUC は 0.708 であった【要確認：本研究のデータで再計算する】。そこで、AP と PA に分けて分類性能と整合の指標を求め、根拠の傾向が撮影方向で変わらないかを確かめる。
2. **写り込み**：文字マーカー、チューブやカテーテル、心電図の電極など、所見と関係のない写り込みに CAM が反応していないか、また modelB の BOX がそれらを検出していないかを目視で確かめる。CAM の最大値や BOX が肺野の外にある画像は、特に詳しく確かめる。
3. **BBox の付け忘れ**：多くの画像は1人の読影医が読んでいる。BBox の外の反応が、付け忘れた陰影に当たっている可能性がある。複数（3人）の読影医が読んだ画像でも同じ傾向が出るかを確かめる。

これらで説明できない反応が、多くの画像で同じ解剖学的な位置に繰り返し現れる場合に、「確からしい根拠」の候補とする。候補については、指導教員や専門医の意見を聞いて最終的に判断する。
